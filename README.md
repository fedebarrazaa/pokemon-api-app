# App Pokémon 

Una pequeña aplicación web que permite **explorar Pokémon**, ver sus tipos y estadísticas básicas.  
Construida con **HTML, CSS, JavaScript, Parcel y Contentful**.

## 🎯 Objetivo del juego

El objetivo de la app es **brindar una experiencia interactiva para descubrir Pokémon**.  
El usuario puede:
- Buscar Pokémon por nombre.
- Ver sus tipos, imagen y estadísticas.
- Explorar múltiples Pokémon y aprender sobre ellos de forma sencilla y visual.

## ⚡ Funcionalidades

- Búsqueda dinámica de Pokémon.
- Visualización de tipos y estadísticas.
- Diseño responsive para móviles y escritorio.
- Contenido gestionado mediante **Contentful CMS**.

## 🛠 Tecnologías utilizadas

- **HTML / CSS / JavaScript** (Front-end)
- **Parcel** (Build tool)
- **pnpm** (Gestor de dependencias)
